# Sofiya Yasin - Personal Portfolio

![Portfolio Screenshot](./public/images/portfolio-screenshot.png) <!-- Add a screenshot later -->

A modern, responsive personal portfolio website built with **React** and **Tailwind CSS**. This portfolio showcases my skills, experience, projects, and certifications as a Full-Stack Web Developer.

🔗 **Live Demo**: [https://sofi3406.github.io/portfolio](https://sofi3406.github.io/portfolio) <!-- Update with your actual URL after deployment -->

---

## ✨ Features

- **Fully Responsive** – Optimized for all devices (mobile, tablet, desktop).
- **Interactive UI** – Smooth animations, hover effects, and a dynamic navbar.
- **Sections**:
  - Hero with animated background and contact info.
  - Professional summary.
  - Technical skills with categorized cards and icons.
  - Work experience timeline.
  - Featured projects with hover effects.
  - Education with university logo.
  - Certifications & training.
  - Contact form (opens email client) and direct links to GitHub, Telegram, etc.
- **Active Link Highlighting** – Navbar updates based on the section in view.
- **Downloadable Resume** – One-click download of PDF resume.
- **Modern Styling** – Gradient backgrounds, blur effects, and consistent color palette.
